# Project Notes

## Main Modules
1. User Portal – profile linking, account and consent.
2. Source Connectors – permitted public or partner sources.
3. AI Analysis – image matching and manipulation signals.
4. Owner Review – private alert and owner decision.
5. Reporting – evidence and platform report request.
6. Secure Data Store – encrypted reference images, consent records and audit logs.

## Prototype Demonstration
- Register an owner photo.
- Upload a test altered image.
- Display match and risk indicators.
- Record the owner's decision.
- Generate a report pack.

## Evaluation Measures
- Match precision and recall
- False-alert rate
- Time to alert
- Owner decision completion
- Report status tracking
